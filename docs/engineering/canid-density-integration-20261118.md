# Dense component integration over the current optical fixes

The full head previously exceeded prepared-geometry admission because unused base layouts were retained alongside draw-selected layouts. Actual round-fiber ears additionally exceeded the old aggregate triangle/draw bounds and the optimized picking token's exact numeric range. This integration preserves local main's transmission and authored-UV0 anisotropy fixes while repairing those component-rendering failures.

Validated source is `322c8128f2e8ed0682cb9c74848874bc701cf11e`, based on `fff48566af7b769a8e46706853e201b9d1e8f78c`. It integrates private `da1110c` and `96bf904` as `0265d1c` and `322c812`. The cache conflict was resolved by retaining both UV identities in compiler options and cache keys, selecting the anisotropic UV0/secondary layout before admission, and retaining a cold untextured layout only when it is actually drawn. No intermediate unused layout consumes the resident geometry budget.
