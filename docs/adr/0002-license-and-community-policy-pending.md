# ADR-0002: License and community policy are pending a business decision

## Status

Open decision; no code license is asserted by this checkout.

## Context

The engineering specification recommends a permissive license such as
Apache-2.0 or MIT, but also requires an explicit CLA/DCO choice, trademark
policy, and dependency notice policy. Those are legal/business decisions, not
implementation details an agent should invent.

## Decision

Do not add a guessed license file or represent Cartographer as redistributable
until the owner records the selected policy. Keep provenance, dependency
boundaries, and the public/private separation documented in the meantime.
